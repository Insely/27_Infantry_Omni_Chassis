# 目录调整

本次只整理工程布局、构建路径和调试配置，控制代码未改动。

- 两个工程的目录格式与 fold 对齐；根目录只保留 Gimbal / Chassis 两个工程。
- BoardLink 放回各板 User/Software/Infantry；原公共参数合并回各板 User/System/robot_param.h。
- Makefile 只引用本工程文件，可单独复制任意一块板编译。
- .vscode / debug 使用对应 fold 工程模板，ELF 路径已修改为本板名称，去除模板中的个人电脑路径和探针序列号。
- 说明和测试收纳到 .doc/AI修改记录；生成物位于 build。
- 两板联测脚本需要两块板作为相邻工程存在；单板固件编译无需另一块板。
- 修改兵种、通信或共享硬件参数时，同步修改两板 robot_param.h；两份 BoardLink 协议必须同步维护。
